Política de privacidade — thor-gmail

O thor-gmail é uma ferramenta pessoal, usada apenas pelo próprio dono da conta Google em que foi autorizada.

  • Usa somente o escopo gmail.readonly: lê mensagens e etiquetas, não envia, não apaga, não altera nada.
  • Os dados lidos ficam no computador do próprio dono e não são vendidos, compartilhados nem transferidos a terceiros.
  • Nenhum dado de outras pessoas é coletado. A ferramenta não tem usuários além do dono.
  • O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso de dados recebidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.
